# AI Werewolf Arena

一个免费、本地运行的“多 AI 狼人杀上帝控制台”。它不调用任何 AI API：上帝把程序生成的中文 Prompt 复制到不同 AI 网页，再将回复粘贴回来。程序负责信息隔离、阶段推进、行动解析、投票、技能结算、胜负判断和本地存档。

> 模型厂商名称只作为用户自行填写的标签。相关商标归各自所有者所有。本项目与任何模型厂商均无官方关系。

## 功能

- 经典 7 人局：2 狼人、预言家、女巫、猎人、2 村民；支持随机或手动分配。
- 完整上帝控制状态机，AI 输出不能自行推进阶段。
- 狼人一致意见、预言家查验、女巫双药限制、猎人开枪条件、平票 PK 与阵营胜负结算。
- 公共信息、玩家私人信息、回复和上帝日志逻辑隔离。
- Prompt 模板按通用规则和角色拆分，包含提示注入防护边界。
- 回复先解析预览，再由上帝确认；解析失败可手动指定行动。
- 深色桌游控制台提供阶段轨迹、行动进度、响应式布局与一键隐私遮罩。
- 本地 JSON 原子存档并保留恢复备份；可新建、继续、撤销上一步和二次确认删除。
- 完整存档支持导出和复制导入，不会覆盖已有对局；旧版存档可自动迁移。
- 进行中可导出不泄密的 Markdown 公开战报；结束后可导出 Markdown 完整复盘。
- 刷新浏览器后从服务端存档恢复，不使用数据库、遥测或外部网络请求。

## 环境与安装

需要 Node.js 20+ 和 npm（Windows、macOS、Linux 均可）。

```bash
npm install
npm run dev
```

打开终端显示的地址（前端通常为 `http://127.0.0.1:5173`）。开发模式同时启动 Vite 前端和 Express 服务。

生产构建与运行：

```bash
npm run build
npm start
```

然后打开 `http://127.0.0.1:3001`。

## 玩法

1. 新建对局，填写玩家名称和用于区分网页的“模型标签”，选择随机或手动身份。
2. 在身份确认页由上帝核对座位，然后正式开始。
3. 对当前等待行动的玩家生成 Prompt 并复制到对应 AI 网页。
4. 把回复粘贴回行动工作台，点击解析，检查预览后确认提交。严格解析失败时可主动使用“宽松重试”，仍无法解析时再用手动模式。
5. 所有必要行动收齐后，由上帝点击“推进至下一阶段”。狼人意见不一致时选择裁定目标或空刀。
6. 对局自动保存。公开战报可随时导出；完整复盘只在游戏结束后开放。完整存档备份可在大厅重新导入，并作为新对局保存。

## 默认规则

首夜是否允许女巫自救可配置，此后不可自救；同夜不能使用两瓶药。猎人被狼刀或放逐时可开枪，被毒死不能开枪。首轮平票进入 PK，PK 再平票无人出局。死亡身份是否公开可配置，默认不公开。狼人全灭则好人获胜；存活狼人数达到存活好人数则狼人获胜。夜间死亡是否有遗言可在建局时配置。

## 隐私模型

服务端保留完整状态，前端上帝控制台可以按开关查看身份。每次生成玩家 Prompt 都由服务端按该玩家身份和当前阶段重新组装：狼人只获得狼队友，预言家只获得自己的查验记录，女巫只获得允许看到的当夜信息和自身药物状态。公共发言被包在不可信游戏内容边界内，不作为系统规则。

本项目的“隐私”是本地主持流程中的逻辑隔离：上帝拥有机器和存档的完全访问权。不要把整个控制台展示给参赛玩家。运行数据位于 `data/games/`，已加入 `.gitignore`。完整存档备份包含身份、私人行动和原始回复，应按私人文件保管；需要公开分享时只使用公开战报。

```text

src/game/           纯规则引擎与回复解析器
src/prompts/        通用及角色 Prompt 模板
src/shared/         前后端共享类型
```

## 已知限制

- MVP 的随机身份分配固定为 7 人经典配置；手动模式可创建至少 5 人对局，但规则平衡由上帝负责。
- 采用半自动复制/粘贴，不控制第三方网页，也不实现浏览器自动化或 API adapter。
- 一台服务实例适合一名本地上帝，不含登录、多用户并发和存档加密。
- 当前存档迁移支持无版本号 MVP 存档和 schema v1；更高版本会被安全拒绝，不会强行降级覆盖。
- 自然语言解析有意保持保守：只有规定标记会生成候选行动，最终仍需人工确认。
- 游戏规则采用项目内置版本，暂不支持自定义角色或复杂房规。

## 安全说明

当前版本不需要 `.env` 或密钥。未来 adapter 的密钥只能保存在本地 `.env`，不得提交 Cookie、会话数据、真实私人对局或任何凭据。默认服务仅监听 `127.0.0.1`。
